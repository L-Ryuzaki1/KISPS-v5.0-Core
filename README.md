# КИСПС v5.1: Вычислительное ядро и Монитор Синхронизации Мультивселенной

Модульная автономная стохастическая система **КИСПС v5.1** (Квантово-Информационный Симулятор Поведенческих Сред). 

В версии v5.1 архитектура переведена с консольных скриптов на полноценный интерактивный веб-комплекс с изоляцией квантово-механических расчетов и многоагентным анализом среды.

## ⚛ Новое в версии v5.1 (Quantum Bell Engine Integration)

- **Изоляция математического контура:** Квантовые вычисления Белла полностью вынесены из основного цикла Монте-Карло в выделенный автономный модуль `quantum_bell_core.py`.
- **Инжекция тригонометрического сдвига:** Внедрен оператор `QuantumBellEngine`, накладывающий тригонометрические модификаторы Белла (\(\cos(2\Delta\theta)\)) на стохастический квантовый поток данных до фазы апдейта состояний. Это позволило преодолеть «плоский» классический рандом и симулировать квантовую запутанность траекторий.
- **Интерактивный Скрытый Слой (Streamlit GUI):** Развернут полноценный веб-интерфейс управления симуляцией, включающий пульт авторизации Суверенного Разработчика, динамическое управление фазовым углом (α) и живой мониторинг квантового отклика.
- **Многоагентный контур (ABM):** Внедрена вкладка управления оцифрованными профилями социума для оценки когерентного буста и деструктивного дренажа векторов альтернативных «Я».

```text
├── modules/                         # Вспомогательные модули и изолированные скрипты связи
│   ├── bridge_kisps_v51.py          # Мост управления изолированной симуляцией v5.1
│   ├── dev_access.py                # Контур верификации и мастер-доступа разработчика
│   ├── quantum_qec_v51.py           # Алгоритм квантовой коррекции ошибок (QEC)
│   ├── security_gate.py             # Семантический шлюз валидации реальности
│   ├── step1_prognosis_engine.py    # Модуль прогнозирования и анализа фазового пространства
│   ├── step1_text_analyzer.py       # Текстовый анализатор траекторий двойников
│   ├── step3_agents.py              # Внешний модуль запутывания квантовых потоков
│   └── step3_multiverse_chat.py     # Интерактивный контур чата параллельных реальностей
├── app.py                           # Главный файл веб-интерфейса Streamlit
├── kisps_core.py                    # Модифицированный абстрактный движок Монте-Карло КИСПС
├── quantum_bell_core.py             # Изолированный математический движок игры Белла
```

## 🛠 Технический стек и запуск

Для работы визуализатора, 3D-проекций и интерфейса требуются следующие зависимости:

```bash
pip install numpy pandas streamlit plotly matplotlib requests
```

Запуск веб-приложения монитора синхронности осуществляется из корневой директории:

```bash
streamlit run app.py
```

## 🧠 Ключевые метрики мониторинга

1. **Индекс Когнитивного Диссонанса Мультивселенной ($\sigma$):** Процентный коэффициент расхождения альтернативных траекторий, рассчитываемый на основе стандартного отклонения успехов выживших двойников.
2. **Топологическая матрица квантового сцепления:** Динамическая тепловая карта смежности, отражающая силу резонанса и запутанности между репрезентативными ветками «Я».
3. **Фазовое пространство:** Автоматический рендеринг 3D-облака из 1000 параллельных реальностей в координатах: *Успех Сигмоиды*, *Износ ЦНС (Гомпертц)* и *Когнитивный Фокус*.
