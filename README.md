# КИСПС v5.0: Вычислительное ядро Мультивселенной (Quantum Behavioral Engine)

Вычислительное ядро автономной стохастической системы **КИСПС v5.0** (Квантово-информационный симулятор поведенческих сред). 

Проект моделирует индивидуальные и мультиагентные траектории методом Монте-Карло, основываясь на гипотезе цифровой Вселенной на стыке квантовой информатики, теории сложных систем и марковских процессов.

## ⚛️ Основные функции ядра:
* **`generate_quantum_shift`** — Симуляция извлечения истинной случайности из флуктуаций вакуума (физический источник энтропии **ANU QRNG**) для исключения скрытого детерминизма среды.
* **`calculate_cns_step`** — Расчет экспоненциального износа Центральной Нервной Системы поведенческих агентов по асимметричной модели Гомпертца-Мейкхама.
* **`evaluate_sigmoid_success`** — Расчет вероятности "Квантового Бунта" (волевого преодоления барьера рутины) через логистическую функцию Сигмоиды.
* **`simulate_sandbox_sleep`** — Симуляция фазы сна в изолированной виртуальной "песочнице" (Sandbox Simulation) для автоматической дефрагментации кэша логов ЦНС.

```bash
pip install numpy
```

## 📜 Использование
Класс `QuantumBehavioralEngine` используется в бэкенд-архитектуре локального веб-приложения для просчета и рендеринга "Живого Веера" 1000 параллельных реальностей.

```python
from engine import QuantumBehavioralEngine

# Инициализация ядра разработчика (Дисциплина=70, Коэффициент резонанса=0.20)
engine = QuantumBehavioralEngine(discipline=70.0, w_resonance=0.20)

# Расчет квантового шага
dq = engine.generate_quantum_shift()
success_rate, focus_left = engine.evaluate_sigmoid_success(focus_prev=100.0, cns_wear=30.0, s_pressure=2.0, delta_q=dq)
```
